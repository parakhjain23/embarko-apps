# Proofboard

A daily task manager a manager can judge in ten seconds.

- One main goal a day. It is done only with proof (a link or a note).
- The score is main goals done this week. Small tasks are shown but never counted.
- A set goal cannot be changed or deleted, so a missed day stays visible.
- Integrations sends the day's report to the manager's Slack, email, etc. every evening.

Run: `npm run dev`. Check the scoring rules: `npm run check`.
Data lives in `DATA_DIR/board.json` (`.data/` locally).
